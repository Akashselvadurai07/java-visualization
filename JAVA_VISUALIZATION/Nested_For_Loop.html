Nested Loops: Managing 2D Structure

A nested loop is perfectly suited for working with two-dimensional arrays or grid structures. Every full execution of the inner loop builds a single horizontal "row" before dropping down.

The Mechanics

for (int i = 0; i < 3; i++) {       // The "Outer" Row Loop
    for (int j = 0; j < 3; j++) {   // The "Inner" Column Loop
        System.out.print("(" + i + "," + j + ") ");
    }
    System.out.println();           // The Newline trigger
}
  • Real-Time Tracking: Watch the Variable Tracking panel on the right. When a value is printed to the console, its corresponding color-coded cell is activated in the 2D array matrix simultaneously.
  • The Row Builder: We use System.out.print() (without the 'ln') so that coordinates print horizontally side-by-side matching the columns in the grid matrix.
  • The Newline: Once the inner loop completes all its j cycles, execution drops back out. We immediately call System.out.println() to push the console cursor to the next line before starting the next row.

Detailed Notes: Nested for Loops in Java

1. Definition

A nested for loop is a for loop placed inside another for loop. The outer loop controls the main/repeated process, while the inner loop runs completely for every single iteration of the outer loop. Multiple levels of nesting are possible.

General Structure:

Outer Loop
    ↓
    Inner Loop
        ↓
        Statements

2. How a Nested Loop Works

Suppose the outer loop executes N times and the inner loop executes M times for each outer iteration. Then the inner statements execute N × M times.

Example Concept: If the outer loop runs 3 times and the inner loop runs 4 times: 3 × 4 = 12 executions. The inner loop completes all 4 iterations before the outer loop moves to its next iteration.

3. Execution Order

Nested loops follow this order:

  1. Outer loop starts.
  2. Inner loop starts.
  3. Inner loop completes all its iterations.
  4. Outer loop moves to the next iteration.
  5. Inner loop starts again.

Important Point: The inner loop is restarted for every iteration of the outer loop.

4. Time Complexity

Time complexity describes how the number of operations grows as the input size increases. For nested loops, the most important question is: How many times does the innermost operation execute?

5. Two Nested Loops

When both loops depend on N, operations = N × N. Therefore, the Time Complexity is O(N²). This is called quadratic time complexity.

6. Two Different Input Sizes

If the outer loop has N iterations and the inner loop has M iterations, then operations = N × M. Time Complexity is O(N × M). Do not automatically write O(N²) unless both input sizes are represented by the same N.

7. Three & Four Nested Loops

  • Three Loops: N × N × N. Time Complexity = O(N³) (Cubic).
  • Four Loops: N × N × N × N. Time Complexity = O(N⁴).

9. General Rule

If there are K nested loops and every loop executes N times, the total executions is Nᴷ. Time Complexity: O(Nᴷ).

10. Nested Loop Does Not Always Mean O(N²)

This is a very important concept. The number of nested loops alone does not determine the time complexity. For example, if the outer loop takes N iterations and the inner loop takes a constant 10 iterations: Total = N × 10. Since constants are ignored, Time Complexity is O(N). So: Nested loop ≠ automatically O(N²).

11. Constant Inner Loop

If the inner loop always executes a fixed number of times, such as 5, 10, or 100: N × Constant. Therefore, Time Complexity is O(N). The constant does not grow with the input.

12. Inner Loop Depends on Outer Loop

Sometimes the number of inner-loop iterations changes depending on the outer-loop value. For example, the inner loop may execute: 1 + 2 + 3 + 4 + ... + N. The total is N(N + 1) / 2. Expanding this gives (N² + N) / 2. For Big-O analysis, constants and lower-order terms are ignored. Therefore, Time Complexity is O(N²).

14. Nested Loop With Logarithmic Inner Loop

Sometimes the inner loop does not increase one-by-one. It may repeatedly Double, Halve, Multiply by a constant, or Divide by a constant. Such a loop generally takes O(log N) operations. If the outer loop takes N operations: N × log N. Therefore, Time Complexity is O(N log N).

16. Nested Loops and 2D Data

Nested loops are commonly used to process two-dimensional data. A two-dimensional structure has Rows and Columns. If there are R rows × C columns, then processing every element requires R × C operations. Time Complexity = O(R × C). If rows and columns are both N: O(N²).

17. Nested Loops and Pattern Problems

Nested loops are commonly used for: Star patterns, Number patterns, Character patterns, Matrix processing, Row and column operations, and Searching in two-dimensional data. For an N × N pattern: N × N = N². Time Complexity is O(N²).

18. Nested Loop vs Sequential Loop

  • Nested: When one loop is inside another, Multiply the number of iterations. (e.g., N × N = N²).
  • Sequential: When loops execute one after another, Add the number of iterations. (e.g., N + N = 2N, ignoring the constant, it is O(N)).

19. Effect of break

A break can stop the inner loop before it completes. Therefore, the actual execution may be smaller. However, for worst-case time complexity, if the inner loop can still run N times: Worst Case is O(N²). Always consider the worst-case number of iterations when determining Big-O unless specifically asked for best or average case.

20. Effect of continue

continue skips the remaining work of the current iteration and moves to the next iteration. It does not necessarily terminate the loop. Therefore, if the loops still perform N × N iterations, the Time Complexity remains O(N²).

21. Space Complexity of Nested Loops

Nested loops mainly affect time complexity. If the loops use only a fixed number of variables and do not create additional data structures, Space Complexity is O(1). It is completely possible to have Time Complexity → O(N²) but Space Complexity → O(1).

22. How to Find Nested Loop Time Complexity

Use these steps:

  1. Identify the outer loop: Find how many times it executes.
  2. Identify the inner loop: Find how many times it executes for each outer iteration.
  3. Multiply: Outer iterations × Inner iterations.
  4. If there are more levels: Multiply each level.
  5. Simplify: Remove constants and lower-order terms.

23. Important Complexity Examples

  • Case 1: Outer: N | Inner: N ➔ N × N = N² ➔ O(N²)
  • Case 2: Outer: N | Inner: M ➔ N × M ➔ O(NM)
  • Case 3: Outer: N | Inner: 10 ➔ 10N ➔ O(N)
  • Case 4: Outer: N | Inner: log N ➔ N log N ➔ O(N log N)
  • Case 5: Three loops, each N: ➔ N³ ➔ O(N³)

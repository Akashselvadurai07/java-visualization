1. What is a Unary Operator?

A Unary Operator is an operator that works with only one operand (value/variable).

Example

int number = 10;
number++;

Here:

  • number → operand
  • ++ → unary operator

So, ++ operates on only one variable.

2. Types of Unary Operators

Java mainly has the following unary operators:

OperatorNamePurpose
+Unary PlusIndicates a positive value
-Unary MinusChanges the sign of a value
++IncrementIncreases value by 1
--DecrementDecreases value by 1
!Logical NOTReverses a boolean value
~Bitwise ComplementInverts the bits of a number

3. Unary Plus +

Definition

The Unary Plus (+) operator indicates that a value is positive. It is placed before a single operand.

Example

int number = 10;
int result = +number;
System.out.println(result);

Output: 10

Real-world example

Think of a bank balance:

int balance = +5000;

The + indicates that the balance is positive. Note: Unary + usually does not change the value.

4. Unary Minus -

Definition

The Unary Minus (-) operator changes the sign of a value. Positive becomes negative, and negative becomes positive.

Example 1

int temperature = 25;
int result = -temperature;
System.out.println(result);

Output: -25

Example 2

int number = -10;
int result = -number;
System.out.println(result);

Output: 10

Real-world example

If a transaction is an expense:

int expense = -500;

The negative sign represents money going out.

5. Increment Operator ++

Definition

The Increment (++) operator increases the value of a variable by 1.

value = value + 1

There are two types:

  • Pre-increment → ++variable
  • Post-increment → variable++

5.1 Pre-Increment ++variable

Definition: In pre-increment, the value is increased first, and then the updated value is used.

int count = 10;
int result = ++count;
System.out.println(result);
System.out.println(count);

Output:
11
11

Execution:
count = 10
++count → 11
result = 11

Easy Rule: Increase first → Use later

5.2 Post-Increment variable++

Definition: In post-increment, the current value is used first, and then the value is increased by 1.

int count = 10;
int result = count++;
System.out.println(result);
System.out.println(count);

Output:
10
11

Execution:
count = 10
result = 10
count becomes 11

Easy Rule: Use first → Increase later

6. Decrement Operator --

Definition

The Decrement (--) operator decreases the value of a variable by 1.

value = value - 1

There are two types:

  • Pre-decrement → --variable
  • Post-decrement → variable--

6.1 Pre-Decrement --variable

Definition: In pre-decrement, the value is decreased first, and then the updated value is used.

int count = 10;
int result = --count;
System.out.println(result);
System.out.println(count);

Output:
9
9

Execution:
count = 10
--count → 9
result = 9

Easy Rule: Decrease first → Use later

6.2 Post-Decrement variable--

Definition: In post-decrement, the current value is used first, and then the value is decreased by 1.

int count = 10;
int result = count--;
System.out.println(result);
System.out.println(count);

Output:
10
9

Execution:
count = 10
result = 10
count becomes 9

Easy Rule: Use first → Decrease later

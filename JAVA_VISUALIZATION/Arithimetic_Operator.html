1. What is an Operator?

An operator is a symbol that tells the computer to perform a specific operation on one or more values.

Simple Example:

int a = 10;
int b = 20;

int result = a + b;

Here:

10 + 20
 │  │  │
 │  │  └── Operand
 │  └───── Operator
 └──────── Operand

The + tells Java to add the two values. So:
Operator = A symbol used to perform an operation on data.

2. Real-Time Example of an Operator

Imagine a shopping application. You purchase:

Laptop        ₹50,000
Mouse          ₹1,000
--------------------
Total         ₹51,000

The application has to calculate: 50000 + 1000.

  • 50000 → Operand
  • + → Operator
  • 1000 → Operand

The + operator tells Java to perform addition. So operators are basically the instructions used to perform operations on data.

3. Types of Operators in Java

Java operators are mainly classified into different types based on the operation they perform:

  • Arithmetic
  • Relational
  • Logical
  • Assignment
  • Unary
  • Conditional
  • Bitwise

4. Arithmetic Operators

Definition: Arithmetic operators are used to perform mathematical calculations on numeric values.

int a = 20;
int b = 10;

We can perform: Addition, Subtraction, Multiplication, Division, and Remainder.

5. Arithmetic Operator Symbols

Java provides 5 basic arithmetic operators:

SymbolOperatorPurpose
+AdditionAdds two values
-SubtractionFinds the difference
*MultiplicationMultiplies two values
/DivisionDivides one value by another
%ModulusFinds the remainder

6. Addition +

The + operator is used to add two values.

int a = 10;
int b = 20;
int result = a + b;
System.out.println(result); // 30

Real-Time Example: Shirt (₹800) + Pant (₹1200) = Total (₹2000)

7. Subtraction -

The - operator is used to subtract one value from another.

int salary = 30000;
int expenses = 12000;
int balance = salary - expenses;
System.out.println(balance); // 18000

Real-Time Example: Bank Balance (₹30,000) - Withdraw (₹12,000) = Remaining (₹18,000)

8. Multiplication *

The * operator is used to multiply two values.

int price = 500;
int quantity = 4;
int total = price * quantity;
System.out.println(total); // 2000

Real-Time Example: 1 shirt (₹500) × Quantity (4) = Total (₹2000)

9. Division /

The / operator is used to divide one value by another.

int totalMarks = 450;
int subjects = 5;
int avg = totalMarks / subjects;
System.out.println(avg); // 90

Real-Time Example: Total Marks (450) / Subjects (5) = Average (90)

10. Modulus %

Definition: The % operator is used to find the remainder after division.

int number = 17;
int remainder = number % 5;
System.out.println(remainder); // Output: 2

Because: 17 ÷ 5 = 3 (15). 17 - 15 = 2. Therefore, 17 % 5 = 2.

11. Real-Time Example of Modulus

Imagine a bus seating system. There are 17 students and 5 students per bus. We can find how many students are left after filling complete groups:

int students = 17;
int capacity = 5;
int remaining = students % capacity;
System.out.println(remaining); // Output: 2

12. Important Difference Between / and %

This is very important for students.

int a = 17;
int b = 5;

// Division (a / b) Result: 3
// Modulus  (a % b) Result: 2

Think like this:

        3  ← Quotient (/)
       ----
5  )  17
      15
      --
       2  ← Remainder (%)

Therefore:
/ → How many complete groups?
% → How many are left?

13. One Complete Example

public class Main {
    public static void main(String[] args) {
        int a = 20;
        int b = 6;

        System.out.println("Addition       : " + (a + b)); // 26
        System.out.println("Subtraction    : " + (a - b)); // 14
        System.out.println("Multiplication : " + (a * b)); // 120
        System.out.println("Division       : " + (a / b)); // 3
        System.out.println("Remainder      : " + (a % b)); // 2
    }
}

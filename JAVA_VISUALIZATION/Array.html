ARRAY — DETAILED NOTES

1. Definition

An Array is a linear data structure used to store multiple values of the same data type under a single variable name.

Example Concept: Suppose we need to store marks of 5 students: 80, 90, 75, 85, 95. Instead of maintaining 5 separate variables, an array stores all the values together.

2. Need for an Array

Arrays are useful when:

  • Multiple values need to be stored.
  • All values belong to the same data type.
  • Values need to be accessed using positions.
  • We need to process many values using loops.
  • Searching, sorting, counting, and other operations need to be performed.

3. Characteristics of an Array

  • 1. Homogeneous: An array generally stores elements of the same data type. (e.g., Integer Array `[10] [20] [30] [40]`)
  • 2. Fixed Size: Once an array is created with a particular size, its size cannot normally be changed.
  • 3. Indexed: Each element is identified using an index.
  • 4. Ordered: Elements are stored in a specific sequence.
  • 5. Direct Access: An element can be accessed directly using its index.
  • 6. Linear Structure: Elements are logically arranged one after another.

4. Array Elements

The individual values stored inside an array are called elements.

[10] [20] [30] [40] [50]

Here:
10 → Element
20 → Element
30 → Element
... Total number of elements = 5

5. Array Index

An index represents the position of an element in an array. In Java, array indexing starts from 0.

Element:   10    20    30    40    50
           ↓     ↓     ↓     ↓     ↓
Index:      0     1     2     3     4

First element → index 0
Second element → index 1
Third element → index 2

6. Why Does Index Start From 0?

Array indexing is based on the position relative to the beginning of the array. Therefore, the first position is represented as 0. For an array containing n elements: First index = 0, Last index = n − 1.

7. Array Size

Array size represents the number of elements that an array can contain.

[10] [20] [30] [40] [50]

Size = 5
Last Index = 4

Important: Last Index = Size − 1

8. Declaration

Array declaration means telling the programming language that an array variable is required. It specifies: Data type, Array indicator `[]`, Variable name.

Example concept: Integer → Array → marks

9. Array Creation

Array creation means allocating memory/storage for the required number of elements. For example, an integer array of size 5 creates empty space. After values are stored, it looks like `[10] [20] [30] [40] [50]`.

10. Array Initialization

Initialization means assigning initial values to the array elements. The values are assigned to different index positions.

11. Accessing Array Elements

An array element is accessed using its index. If we need 30, we access the element at index 2.

12. Updating an Array Element

An existing element can be replaced with another value. Only that particular element changes.

Before: [10] [20] [30] [40] [50]
Suppose the value at index 2 is changed.
After:  [10] [20] [100] [40] [50]

13. Traversal

Traversal means visiting each element of an array one by one. During traversal, every element is processed. It is commonly used for Printing, Summing, Finding min/max, Searching, and Counting.

14. Searching

Searching means finding whether a particular value exists in an array. Linear search checks elements one by one from beginning to end.

[10] [25] [30] [45] [50]
Search for 30.
10 → 25 → 30
           ↑
         Found

15. Insertion

Insertion means adding a new element into an array. Because a normal array has fixed size, insertion may require creating a larger array, or shifting existing elements.

16. Deletion

Deletion means removing an element from an array. The elements after the deleted element may need to be shifted.

17. Updating

Updating means replacing an existing value with a new value (e.g., Update 30 → 100).

19. One-Dimensional Array

A one-dimensional array stores elements in a single linear sequence. It has only one index. Conceptually: Array[index]

20. Two-Dimensional Array

A two-dimensional array stores data in the form of rows and columns. Commonly used to represent matrices, tables, boards, or grids.

        Column
        0    1    2
Row 0  [10] [20] [30]
Row 1  [40] [50] [60]
Row 2  [70] [80] [90]

21. Row and Column

In a 2D array, horizontal arrangement → Row, Vertical arrangement → Column. A 3x3 array has 3 rows, 3 columns, and 9 elements.

22. Multidimensional Arrays

An array can have more than two dimensions (e.g., 1D → List, 2D → Table/Matrix, 3D → Collection of tables).

23. Array and Memory

Conceptually, an array can be viewed as a group of storage locations. Each position has an index which allows direct access to a particular element.

24. Fixed Size

One of the most important characteristics of an array is its fixed size. The program needs another mechanism, such as creating a new larger array or using a dynamic collection to resize it.

25. Advantages of Arrays

  • 1. Simple: Arrays are easy to understand and use.
  • 2. Fast Access: Elements can be directly accessed using an index.
  • 3. Easy Traversal: Loops can easily process all elements.
  • 4. Memory Organization: Elements are organized systematically.
  • 5. Algorithms: Many algorithms use arrays as their basic data structure.

26. Disadvantages of Arrays

  • 1. Fixed Size: The size cannot normally be changed after creation.
  • 2. Insertion/Deletion Can Be Expensive: Adding or removing an element in the middle may require shifting elements.
  • 3. Same Data Type: A normal array generally stores elements of the same type.

29. Common Array Problems

Basic: Print all elements, Print in reverse, Find sum, Find average, Count even/odd elements, Find min/max.

Intermediate: Search an element, Count occurrences, Reverse an array, Find second largest/smallest, Find/Remove duplicates, Check whether array is sorted, Merge two arrays.

Advanced: Array rotation, Pair sum, Maximum subarray, Frequency counting, Two Sum, Single Number.

Quick Revision

  • Array: Collection of elements of the same data type.
  • Element: Individual value stored in an array.
  • Index: Position of an element. First index: 0, Last index: size − 1
  • Size: Number of elements.
  • Traversal: Visiting elements one by one.
  • Searching/Insertion/Deletion/Update: Modifying or scanning array components.
  • 1D/2D Array: Linear list vs rows and columns.

Most important concept: Array stores multiple values, and each value is accessed using its index.

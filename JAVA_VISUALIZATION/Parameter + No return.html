Static Method: Parameter + No Return Type

This type of method requires external data (parameters) to perform its task, but it does not hand back a value to the caller (it has a void return type).

Why use this?

Because it is a static method, it belongs to the class itself. You use this pattern when you want to execute a shared utility function using specific data you provide, without needing an object instance, and you don't need any result sent back to the main program.

Code Syntax

// Method definition accepting parameters but returning void
static void calculateArea(int length, int width) {
    int area = length * width;
    System.out.println(area); // Prints internally, doesn't return
}

// In main method:
calculateArea(5, 10); // Directly pass arguments to the static method

Key Characteristics

Characteristic Description
Static Uses the static keyword. Does not require an object instance to be called.
Parameters The parentheses (int length, int width) specify what data the method needs. When called, the arguments are placed directly into the method's local memory frame.
No Return Type Uses the void keyword. It performs an action (like calculating and printing) but does not pass data back to main().

Memory Perspective

When the static method is called, Java creates a new temporary memory frame on the Stack. The arguments provided (5 and 10) are mapped to the local parameter variables. Once the method completes its task, this entire local memory frame is completely destroyed.

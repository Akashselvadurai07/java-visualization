Java Data Types — Detailed Notes

1. What is a Data Type?

A data type specifies:

  • What kind of value a variable can store
  • How much memory is required
  • What range of values can be stored
  • What operations can be performed on the value

Example

int age = 22;

Here:

  • int → Data type
  • age → Variable
  • 22 → Value

So, int tells Java that age will store an integer value.

4. Integer Data Types

Integer data types are used to store whole numbers.

byte → short → int → long

5. byte

byte is the smallest integer data type in Java.

  • Size: 1 byte = 8 bits
  • Range: -128 to 127
byte age = 22;
System.out.println(age);

Output: 22

Why range is -128 to 127? An 8-bit signed number has 2^8 = 256 values. Therefore: -128 to 127 (Total: 256 values).

6. short

short stores larger integer values than byte.

  • Size: 2 bytes = 16 bits
  • Range: -32,768 to 32,767
short marks = 25000;
System.out.println(marks);

7. int

int is the most commonly used integer data type in Java.

  • Size: 4 bytes = 32 bits
  • Range: -2,147,483,648 to 2,147,483,647
int salary = 28000;
System.out.println(salary);

Important: When you write int x = 100;, 100 is normally treated as an int literal.

8. long

long is used when the integer value is larger than the int range.

  • Size: 8 bytes = 64 bits
  • Range: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
long population = 8000000000L;
System.out.println(population);

Why L? L tells Java that the number is a long literal. Without L (long population = 8000000000;), this causes a compilation error because the integer literal is first treated as an int.

9. Floating-Point Data Types

Floating-point types store numbers containing decimal values. Java provides: float and double.

10. float

float stores decimal values using 32 bits.

  • Size: 4 bytes = 32 bits
float price = 99.50f;
System.out.println(price);

Why f? By default, a decimal literal such as 99.50 is considered a double. Therefore, float price = 99.50; causes an error. Use: float price = 99.50f;

11. double

double stores decimal values using 64 bits.

double salary = 28000.50;
System.out.println(salary);

Decimal literals are normally treated as double. Therefore this is valid: double x = 10.5;

13. char

char is used to store a single character.

  • Size: 2 bytes = 16 bits
char grade = 'A';
System.out.println(grade);

Important: Use single quotes for char. Correct: char ch = 'A'; Incorrect: char ch = "A"; ("A" is a String, not a char).

14. char and Unicode

Java char uses the UTF-16 representation. Therefore it can represent characters from many writing systems.

char a = 'A';
char b = 'க';
char c = '中';

15. Character as a Number

A char internally represents a numeric Unicode value.

char ch = 'A';
System.out.println((int) ch); // Output: 65

Similarly: char ch = 'B'; → Output is 66.

16. boolean

boolean stores logical values. It has only two values: true and false.

boolean isStudent = true;
System.out.println(isStudent); // Output: true

Common usage

int age = 22;
boolean eligible = age >= 18;
System.out.println(eligible); // Output: true

17. Important Point About boolean

Unlike some languages, Java does not allow boolean x = 1; or boolean x = 0;. This is invalid. Java requires boolean x = true; or boolean x = false;.

18. Non-Primitive Data Types

Non-primitive/reference types include things such as: String, Arrays, Classes, Objects, Interfaces, and Enums.

String name = "Akash";

Here: String → Reference type, name → Reference variable.

21. Why Different Data Types?

Suppose int age = 22;. There is no reason to use long age = 22; if the value will always fit comfortably in int. Choosing an appropriate data type helps with memory usage, range requirements, precision, correctness, and program design.

22. Integer Size Hierarchy

A simple way to remember: byte ↓ short ↓ int ↓ long. As we move downward: size increases and range increases. For floating point: float ↓ double.

24. Local Variables Don't Have Default Values

This is important.

class Main {
    public static void main(String[] args) {
        int x;
        System.out.println(x); // Compilation error
    }
}

This produces a compilation error because x has not been initialized. You must do: int x = 10;

25. Literals in Java

A literal is a fixed value written directly in the program. Examples: 10, 100, 10.5, 'A', true, "Java".

int x = 10;
double price = 99.5;
char grade = 'A';
boolean result = true;
String name = "Akash";

26. Integer Literals

Java supports different number systems:

  • Decimal: int x = 10;
  • Binary (0b): int x = 0b1010; (Value: 10)
  • Octal (0): int x = 012; (Value: 10)
  • Hexadecimal (0x): int x = 0xA; (Value: 10)

27. Type Suffixes

Java provides suffixes for certain literals:

  • Long: long x = 100L;
  • Float: float x = 10.5f;
  • Double: double x = 10.5d; (d is optional)

28. Underscores in Numbers

Java allows underscores to improve readability. Instead of int salary = 1000000;, you can write int salary = 1_000_000;. Both represent 1000000. Another example: long population = 8_000_000_000L;

29. Type Conversion

Type conversion means converting one data type into another.

Type Conversion
      |
      +------ Widening
      |
      +------ Narrowing

30. Widening Conversion

Smaller compatible type → larger compatible type. No explicit casting is required.

int x = 100;
long y = x;
System.out.println(y);

Typical numeric widening path: byte ↓ short ↓ int ↓ long ↓ float ↓ double.

31. Narrowing Conversion

Larger type → smaller type. Explicit casting is required.

double x = 10.5;
int y = (int) x;
System.out.println(y); // Output: 10 (decimal part is removed)

32. Casting

Syntax: datatype variable = (datatype) value;

double price = 99.99;
int x = (int) price;
System.out.println(x); // Output: 99

Casting does not round the value. 99.99 → 99.

33. Integer Overflow

Consider:

int x = 2147483647;
x = x + 1;
System.out.println(x); // Result: -2147483648

Why? Because int has a fixed 32-bit signed range. This is called integer overflow.

34. Integer Division

int a = 10;
int b = 3;
System.out.println(a / b); // Output: 3

But: double result = 10 / 3.0; outputs approximately 3.3333333333333335.

35. Important Decimal Precision Example

double x = 0.1;
double y = 0.2;
System.out.println(x + y);

You may see: 0.30000000000000004. This happens because binary floating-point representation cannot represent many decimal fractions exactly.

36. Data Type and Memory

A simplified view: byte → 1 byte, short → 2 bytes, int → 4 bytes, long → 8 bytes, float → 4 bytes, double → 8 bytes, char → 2 bytes.

But remember: memory layout of variables inside the JVM is not simply equivalent to saying every variable always occupies exactly its primitive-width number of bytes, because JVM implementation, object layout, alignment, and storage context can affect actual memory usage.

37. Important Interview Questions

Q1. How many primitive data types are there in Java?
Answer: 8

Q2. Which is the default integer type?
Answer: int

Q3. Which is the default decimal type?
Answer: double

Q4. What is the size of int?
Answer: 4 bytes

Q5. What is the range of byte?
Answer: -128 to 127

Q6. Why is L used?
Answer: long x = 100L; L identifies the literal as a long.

Q7. Why is f used?
Answer: float x = 10.5f; Because decimal literals are normally double.

Q8. Can char store numbers?
Answer: A char stores a UTF-16 code unit, so it can represent numeric character values such as: char ch = 65; which represents 'A'.

Q9. Is String a primitive data type?
Answer: No. String → Reference type

Q10. Does Java have unsigned integer primitive types?
Answer: Java's standard integer primitives (byte, short, int, long) are signed. Java also provides unsigned arithmetic methods for int and long, but the primitive types themselves remain signed.

38. Easy Memory Trick

Remember the 8 primitives as: B S I L | F D | C B

  • B → byte, S → short, I → int, L → long
  • F → float, D → double
  • C → char, B → boolean

Or remember: 4 integer + 2 decimal + 1 character + 1 boolean = 8 primitive types.

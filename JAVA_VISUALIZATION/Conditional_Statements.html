If–Else If–Else Block in Java

The if – else if – else block is used when a program needs to check multiple conditions and execute the block corresponding to the first condition that is true.

1. Syntax

if (condition1) {
    // Statements executed when condition1 is true
} else if (condition2) {
    // Statements executed when condition2 is true
} else if (condition3) {
    // Statements executed when condition3 is true
} else {
    // Statements executed when all conditions are false
}

2. How It Works

The execution evaluates conditions chronologically in this order:

             Start
                |
        Check condition 1
          /          \
       true          false
        |              |
    Execute        Check condition 2
    block            /        \
                  true      false
                   |          |
               Execute    Check condition 3
               block        /      \
                          true     false
                           |          |
                       Execute      else
                       block        block
Important Rule

Java checks conditions from top to bottom. As soon as one condition becomes true:

  • Its block is executed.
  • All remaining else if and else blocks are skipped completely.
  • Control moves to the statement immediately following the entire if–else if–else structure.

3. Real-World Example

int marks = 75;

if (marks >= 90) {
    System.out.println("Grade A+");
} else if (marks >= 80) {
    System.out.println("Grade A");
} else if (marks >= 70) {
    System.out.println("Grade B");
} else if (marks >= 60) {
    System.out.println("Grade C");
} else {
    System.out.println("Fail");
}

Execution breakdown for marks = 75;

  • marks >= 90 → Evaluates to false
  • marks >= 80 → Evaluates to false
  • marks >= 70 → Evaluates to true

Because the third check is true, the program prints Grade B. The remaining conditions (>= 60 and else) are completely ignored and not checked.

4. Multiple Conditions

You can combine conditions inside a single if or else if statement using logical operators:

  • && → AND (Both must be true)
  • || → OR (At least one must be true)
  • ! → NOT (Reverses the boolean value)
int age = 25;
boolean hasLicense = true;

if (age >= 18 && hasLicense) {
    System.out.println("Eligible to drive");
} else if (age >= 18 && !hasLicense) {
    System.out.println("Get a driving license");
} else {
    System.out.println("Not eligible to drive");
}

In this example, age >= 18 && hasLicense must both be true for the first block to execute.

5. Difference Between Multiple if and else if

Multiple if

if (marks >= 70) {
    System.out.println("B");
}
if (marks >= 60) {
    System.out.println("C");
}
if (marks >= 50) {
    System.out.println("D");
}

Each condition is checked independently regardless of the others. For marks = 75, all three conditions are true, so all three statements will execute printing B, C, and D.

else if Chain

if (marks >= 70) {
    System.out.println("B");
} else if (marks >= 60) {
    System.out.println("C");
} else if (marks >= 50) {
    System.out.println("D");
}

Conditions are linked. For marks = 75, only B is printed because Java stops evaluating immediately after finding the first true condition.

6. Important Points Summary

Feature Description
ifChecks the first condition. It acts as the mandatory starting point of the chain.
else ifChecks another condition only when all previous conditions evaluate to false.
elseExecutes automatically when all preceding conditions are false.
Number of else ifYou can link any number of these together.
else requirementIt is strictly optional. A chain can end with an else if.
Execution ruleOnly the first matching block is ever executed.
Condition formatThe statements inside the parentheses must produce a true or false boolean value.
Evaluation OrderConditions are exclusively evaluated from top to bottom.
Key Takeaway Concept

if → else if → else = Choose ONE block from multiple possibilities.

For example grading scales:

  • 90–100 → A+
  • 80–89 → A
  • 70–79 → B
  • 60–69 → C
  • Below 60 → Fail

This "pick exactly one path" scenario is one of the most common and powerful uses of the if–else if–else structure in Java.

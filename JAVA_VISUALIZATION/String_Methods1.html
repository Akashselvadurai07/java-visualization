Java String Methods Explained

Strings in Java come with a powerful set of built-in methods that allow you to manipulate, analyze, and compare text. Because Strings are objects, you call these methods using the dot (.) operator (e.g., s.length()).

1. Finding the Size: length()

The length() method counts the total number of characters in the String, including spaces and special characters.

  • Syntax: s.length()
  • Returns: An integer (int).
String s = "Hello World";
System.out.println(s.length()); // Output: 11

2. Accessing Characters: charAt()

The charAt(index) method returns the single character located at the specified index.

Note: String indexing in Java always starts at 0.
  • Syntax: s.charAt(int index)
  • Returns: A character (char).
String s = "Java";
// J(0) a(1) v(2) a(3)
System.out.println(s.charAt(2)); // Output: v

3. Extracting Parts of a String: substring()

The substring() method extracts a smaller chunk (a sub-string) from the original string. It has two variations:

Variation A: Start to End

  • Syntax: s.substring(beginIndex)
  • Action: Takes everything from beginIndex all the way to the end of the string.
  • Example: "Programming".substring(3) → "gramming"

Variation B: Start to Specific End

  • Syntax: s.substring(beginIndex, endIndex)
  • Action: Takes characters starting from beginIndex up to, but not including, the endIndex.
  • Example: "Programming".substring(0, 4) → "Prog"

4. Changing Case: toUpperCase() & toLowerCase()

These methods convert all the characters in a String to either fully uppercase or fully lowercase letters.

Important Concept: Because Strings are immutable, these methods do not change the original String. Instead, they create and return a brand new String object.
String s = "Java";
System.out.println(s.toUpperCase()); // Output: JAVA
System.out.println(s.toLowerCase()); // Output: java

5. Comparing Strings: equals() & equalsIgnoreCase()

Never use == to compare the actual text of two Strings. Always use these methods!

  • equals(String str): Checks if two strings have the exact same characters in the exact same case.
    "Java".equals("JAVA") → false
  • equalsIgnoreCase(String str): Checks if the contents are the same, completely ignoring whether letters are uppercase or lowercase.
    "Java".equalsIgnoreCase("JAVA") → true

6. Dictionary Order: compareTo()

While equals() just tells you if strings are identical (true/false), compareTo() tells you which string comes first alphabetically (lexicographically).

  • Returns 0: If both strings are exactly equal.
  • Returns a negative number: If the first string comes before the second string in the dictionary.
  • Returns a positive number: If the first string comes after the second string in the dictionary.

7. Joining Strings: concat()

The concat() method attaches one string to the very end of another.

  • Syntax: s1.concat(s2)
String s1 = "Hello ";
String s2 = "World";
System.out.println(s1.concat(s2)); // Output: Hello World
Using concat() does the exact same thing as using the + operator (s1 + s2).

8. Searching Text: contains()

The contains() method checks if a specific sequence of characters (a word, a letter, or a phrase) exists anywhere inside the String.

  • Syntax: s.contains(searchString)
  • Returns: true if found, false if not found.
String s = "Learn Java Programming";
System.out.println(s.contains("Java")); // Output: true
System.out.println(s.contains("Python")); // Output: false

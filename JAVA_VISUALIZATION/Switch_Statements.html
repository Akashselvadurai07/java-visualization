The Switch Statement in Java

The switch statement allows a variable or expression to be tested for equality against a list of values. Each value is called a case, and the variable being switched on is checked for each case sequentially.

1. Syntax

switch (expression) {
    case value1:
        // Statements executed if expression == value1
        break;
    case value2:
        // Statements executed if expression == value2
        break;
    default:
        // Statements executed if no case matches
}

2. How It Works

Unlike an if-else chain that checks boolean conditions (e.g., x > 10), the switch statement specifically checks for exact equality.

The Fall-Through Behavior (And why we need break)

Once a case match is found, Java starts executing code at that exact line and keeps executing downwards, ignoring subsequent case labels, until it hits a break; statement or the end of the switch block.

This is why the break keyword is crucial. It tells Java to instantly exit the switch block.

3. Real-World Example

int dayOfWeek = 3;
String dayName;

switch (dayOfWeek) {
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break; // Match found, executes this line, then breaks out
    default:
        dayName = "Invalid Day";
}
System.out.println(dayName); // Outputs: Wednesday

4. Valid Data Types for Switch

In modern Java, you cannot switch on every data type. The switch expression must yield one of the following:

  • byte, short, char, int (and their wrapper classes)
  • String (Since Java 7)
  • enum Types

Note: You cannot switch on long, float, double, or boolean values.

The Default Case

The default: block is optional but highly recommended. It acts exactly like the final else in an if-else chain. If absolutely none of the explicitly listed case values match the expression, the code inside the default block will execute.

Type Casting in Java — Basic Notes

1. What is Type Casting?

Type Casting is the process of converting a value from one data type to another data type.

Example

int number = 10;
double value = number;

Here, the int value is converted into a double.

int → double
10  → 10.0

2. Types of Type Casting

Java has two types of type casting:

1. Widening Type Casting

Converting a smaller data type into a larger data type.

Small → Large

Example:

int number = 10;
double value = number;

int → double

Automatically performed by Java.

2. Narrowing Type Casting

Converting a larger data type into a smaller data type.

Large → Small

Example:

double number = 10.5;
int value = (int) number;

Output:

10

Explicit casting is required.

3. Type Casting Diagram

                 TYPE CASTING
                      │
             ┌────────┴────────┐
             │                 │
         Widening           Narrowing
             │                 │
        Small → Large      Large → Small
             │                 │
        Automatic          Explicit
             │                 │
       int → double      double → int

Widening Type Casting

1. What is Widening Type Casting?

Widening Type Casting is the process of converting a smaller data type into a larger data type.
It is also called:

  • Widening Conversion
  • Implicit Casting
  • Automatic Type Conversion

Example

int number = 25;
double value = number;

System.out.println(value);

Output:

25.0

Here:

int → double
25  → 25.0

Java automatically converts the int value into a double.

2. Widening Type Casting Order

byte
  ↓
short
  ↓
int
  ↓
long
  ↓
float
  ↓
double

char can also widen to:

char → int → long → float → double

boolean is not part of numeric type casting.

3. Why is it Called "Widening"?

Think about a container.

Small Box                    Large Box

┌─────────┐                ┌─────────────────┐
│   25    │   ───────►     │       25        │
└─────────┘                └─────────────────┘

A smaller type can generally fit into a larger type.

Example:

int a = 100;
long b = a;

Java automatically converts the int value into long.

4. byte → int

byte a = 25;
int b = a;

System.out.println(a);
System.out.println(b);

Output:

25
25

The value remains the same.

byte
  25
   │
   │ Automatic Conversion
   ▼
int
  25

5. int → long

int number = 100000;
long value = number;

System.out.println(value);

Output:

100000

No explicit casting is required.

6. int → float

int number = 25;
float value = number;

System.out.println(value);

Output:

25.0

7. int → double

int number = 25;
double value = number;

System.out.println(value);

Output:

25.0

8. char → int

This is an interesting example.

char ch = 'A';
int value = ch;

System.out.println(value);

Output:

65

Java stores a char using a Unicode numeric value.

'A'
 │
 │ Widening
 ▼
65

For example:

A → 65
B → 66
C → 67

9. Widening During Calculations

int a = 10;
double b = 5.5;

double result = a + b;

System.out.println(result);

Output:

15.5

Internally:

10          5.5
int         double
 │             │
 └──────┬──────┘
        ↓
     double
        ↓
   10.0 + 5.5
        ↓
       15.5

Java automatically converts the int value into double.

10. Important Point About Precision

Widening does not always mean that every value will be represented exactly.
For example:

int number = 16777217;
float value = number;

System.out.println(value);

float has limited precision, so very large integer values may not be represented exactly.
Therefore:

Widening provides a wider type, but floating-point conversions can still cause precision loss.

11. Widening During Arithmetic

Consider:

byte a = 10;
byte b = 20;

int result = a + b;

System.out.println(result);

Output:

30

Even though both variables are byte, Java promotes them to int during arithmetic.

byte + byte
     ↓
    int

Similarly:

byte  + byte  → int
short + short → int
char  + char  → int

This is called Binary Numeric Promotion.

12. Widening in Assignment

byte b = 10;
short s = b;
int i = s;
long l = i;
float f = l;
double d = f;

The values move through progressively wider types:

byte
 ↓
short
 ↓
int
 ↓
long
 ↓
float
 ↓
double

13. Explicit Casting Is Not Required

Normal widening

int number = 50;
double value = number;

This is sufficient.
You can also write:

int number = 50;
double value = (double) number;

But the explicit cast is unnecessary because Java automatically performs the widening conversion.

14. Real-Life Example

Imagine pouring water from a small glass into a large bottle.

Small Glass
    │
    │
    ▼
Large Bottle

Similarly:

byte → int
int  → long
int  → double

The reverse direction is different:

Large Bottle
    │
    │
    ▼
Small Glass

This represents Narrowing Type Casting.

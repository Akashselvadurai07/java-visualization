Java String Methods Explained

Strings in Java are objects, meaning they come with built-in methods for searching, modifying, and evaluating text. Here is a breakdown of the new methods demonstrated.

1. Searching and Matching

  • contains(CharSequence s): Returns true if the string contains the specified sequence of characters anywhere inside it.
  • startsWith(String prefix): Returns true if the string begins with the specified prefix.
  • endsWith(String suffix): Returns true if the string finishes with the specified suffix.
String s = "Java Programming";
System.out.println(s.startsWith("Java")); // true
System.out.println(s.endsWith("Java"));   // false

2. Finding Positions (Indexes)

You can find where specific characters (or substrings) are located within your String. Remember, indexing starts at 0.

  • indexOf(char ch): Returns the index of the first occurrence of the character. Returns -1 if not found.
  • lastIndexOf(char ch): Returns the index of the last occurrence of the character (searching from right to left).

3. Modifying Strings (Replacing & Trimming)

Important Concept: Strings are immutable. Modifying methods do not change the original string. They return a brand new String object with the changes applied.
  • replace(oldChar, newChar): Swaps all occurrences of a specific character with a new one.
  • replaceAll(regex, replacement): Replaces substrings that match a given regular expression (or exact string) with a replacement string.
  • trim(): Removes any whitespace (spaces, tabs, newlines) from both ends of the string, but leaves spaces in the middle untouched.

4. Checking Empty or Blank States

It's common to need to check if a string actually contains useful text before processing it.

  • isEmpty(): Returns true only if the string length is exactly 0 (e.g., "").
  • isBlank(): Returns true if the string is empty or contains only whitespace characters (e.g., " "). Introduced in Java 11.

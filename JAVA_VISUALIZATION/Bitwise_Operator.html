1. What are Bitwise Operators?

Unlike logical operators that evaluate entire boolean expressions, bitwise operators operate on individual bits of integer data types (like int or byte). They allow precise control over data at the binary level.

2. Types of Bitwise Operators

SymbolOperator NamePurpose
&Bitwise ANDCompares each bit. Returns 1 if both bits are 1.
|Bitwise ORCompares each bit. Returns 1 if at least one bit is 1.
^Bitwise XORCompares each bit. Returns 1 if the bits are different.
~Bitwise NOTInverts all bits (0 becomes 1, 1 becomes 0).
<<Left ShiftShifts bits to the left, filling with zeros on the right.
>>Signed Right ShiftShifts bits to the right, duplicating the sign bit on the left.
>>>Unsigned Right ShiftShifts bits to the right, always filling with zeros on the left.

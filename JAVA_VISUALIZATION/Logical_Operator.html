1. What are Logical Operators?

Logical operators are used to combine multiple boolean expressions or invert the logic of a single boolean expression. They always evaluate to either true or false and are highly prevalent in conditional statements like if statements and while loops.

Simple Example:

boolean hasTicket = true;
boolean isVIP = false;

boolean canEnter = hasTicket || isVIP;

The || operator tells Java to check if at least one of the conditions is true. Because the user has a ticket, canEnter becomes true.

2. Types of Logical Operators

Java provides three core logical operators:

SymbolOperator NamePurpose
&&Logical ANDReturns true only if both operands are true.
||Logical ORReturns true if at least one operand is true.
!Logical NOTReverses the boolean state of its operand.

3. Logical AND &&

Used when all conditions must be met.

int temperature = 25;
boolean isSunny = true;

// Both must be true for perfectWeather to be true
boolean perfectWeather = (temperature > 20) && isSunny;

4. Logical OR ||

Used when meeting any single condition is sufficient.

boolean hasPassword = false;
boolean hasFingerprint = true;

// True if either authentication method passes
boolean loginSuccess = hasPassword || hasFingerprint;

5. Logical NOT !

A unary operator (operates on only one variable) that flips true to false, and vice versa.

boolean isRaining = false;
boolean goOutside = !isRaining; // flips false to true

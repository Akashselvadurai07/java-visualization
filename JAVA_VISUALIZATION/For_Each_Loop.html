Anatomy of an Enhanced For Loop

The enhanced for loop (often called the "for-each" loop) in Java provides a simplified way to iterate through elements in arrays and collections. It hides the complexity of tracking array indices manually.

The Structure

for (type variableName : arrayName) {
    // block of code to be executed
}
  • Array Reference (numbers): This tells Java which collection or array we want to iterate over. It evaluates how many elements are present behind the scenes.
  • Variable Declaration (int num): On every single iteration, Java automatically fetches the next element from the array and assigns it to this variable. You use this variable inside the loop body.
The Implicit Iterator

Unlike a standard for loop, you do not write an initialization (i=0), condition (i < length), or update (i++). The JVM inherently tracks the position in the array. When it runs out of elements to fetch, the loop condition automatically evaluates to false and exits.

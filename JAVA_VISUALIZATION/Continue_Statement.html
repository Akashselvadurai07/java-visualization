The Continue Statement

A for loop repeats a block of code based on a condition. While break destroys the loop entirely, the continue statement allows you to skip parts of the loop, but keep the loop alive.

1. The For Loop Structure

for (initialization; condition; update) {
    // block of code to be executed
}
  • Initialization (e.g., int i = 1): Runs exactly once at the very beginning.
  • Condition (e.g., i <= 5): Evaluated before every iteration. If true, the loop body executes.
  • Update (e.g., i++): Runs exactly once at the end of every successful iteration.

2. The Continue Keyword

When Java encounters a continue; statement, it immediately aborts the current execution path inside the loop body. It skips all remaining code below it and jumps straight to the Update statement (e.g., i++). The loop then proceeds normally.

Why use continue?

It's incredibly useful for filtering. For example, if you are looping through numbers to process odd numbers only, you can use if (isEven) continue; to instantly skip the processing logic for even numbers and move to the next item in the list.

3. Break vs. Continue

Keyword Action Where does execution go?
continue Skips the rest of the current iteration only. Jumps straight to the Update statement (e.g. i++).
break Terminates the entire loop completely. Jumps outside the loop, past the closing brace }.

1️⃣ No Parameter + No Return Type

This is the simplest form of a method in Java. It is self-contained: it does not accept any inputs from the caller (no parameters), and it does not hand any data back when it finishes (return type is void).

static void display() {
    System.out.println("Hello Students");
}

How it Works

  • No Parameter: The empty parentheses () indicate that the method requires zero external inputs to execute.
  • Action Execution: It performs a standalone task—such as printing text to the console or modifying a system state.
  • No Return (void): When execution hits the end of the method body, control returns directly to the caller (`main()`) without carrying any value back.

Crucial Teaching Distinction

Console Output $\neq$ Return Value. Printing a message via System.out.println() displays information on the user screen for viewing. It is not saved in memory or passed back to a variable in the caller method. A true return value requires a type definition (like int or String) and a return keyword.

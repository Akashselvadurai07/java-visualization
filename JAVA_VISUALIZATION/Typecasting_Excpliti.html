Explicit Type Casting in Java — Detailed Notes

1. What is Explicit Type Casting?

Explicit type casting is the process of manually converting a value from one data type to another data type by using the casting operator (type).

Syntax

targetType variable = (targetType) value;

Example

double value = 65.79;
int number = (int) value;

System.out.println(number);

Output:

65

The decimal part .79 is removed.

2. Why is Explicit Casting Required?

Java does not automatically convert every data type because some conversions can cause:

  • Loss of decimal values
  • Loss of numerical range
  • Change in the actual value
  • Unexpected results

For example:

double value = 65.79;
int number = (int) value;

Java requires: (int) because double can store decimal values while int cannot.

3. Basic Explicit Casting Flow

The common numeric casting chain is:

double
   ↓
float
   ↓
long
   ↓
int
   ↓
short
   ↓
byte

The farther we move down, the greater the possibility of data loss.

Example:

double doubleValue = 65.79;

float floatValue = (float) doubleValue;
long longValue = (long) floatValue;
int intValue = (int) longValue;
short shortValue = (short) intValue;
byte byteValue = (byte) shortValue;

Result:

double → 65.79
float  → 65.79
long   → 65
int    → 65
short  → 65
byte   → 65

4. All Primitive Numeric Combinations

Java has these numeric primitive types: byte, short, int, long, float, double. There are also: char, boolean.

Important: boolean cannot be converted to numeric types using casting. For example, this is invalid:

boolean value = true;
int number = (int) value;

Java does not support boolean-to-number casting.

5. double → float

double value = 65.79;
float result = (float) value;
System.out.println(result);

Output: 65.79

Possible issue: float has less precision than double.

double value = 123456789.123456;
float result = (float) value;
System.out.println(result);

The result may not contain exactly the same precision. Important point: double → float can cause precision loss.

6. double → long

double value = 65.79;
long result = (long) value;
System.out.println(result);

Output: 65. The .79 is discarded. It does not round the value: 65.79 → 65, 65.99 → 65.

7. double → int

double value = 99.99;
int result = (int) value;
System.out.println(result);

Output: 99. Important: Casting does not perform normal mathematical rounding. It becomes 99, not 100.

8. double → short

double value = 100.75;
short result = (short) value;
System.out.println(result);

Output: 100. Two things can happen: Decimal part is removed, and if the value is outside short range, overflow can occur.

9. double → byte

double value = 100.75;
byte result = (byte) value;
System.out.println(result);

Output: 100. But byte has a very small range (-128 to 127). So if you do:

double value = 130.75;
byte result = (byte) value;
System.out.println(result);

Output: -126. This is an example of overflow/wrapping.

10. long → int

long value = 100000;
int result = (int) value;
System.out.println(result);

Output: 100000. But if the value is outside the int range:

long value = 3000000000L;
int result = (int) value;
System.out.println(result);

The result will not be 3000000000. The value overflows because int cannot represent that number.

11. int → short

int value = 100;
short result = (short) value;
System.out.println(result);

Output: 100. But if you assign 40000, the result is different because short can only store -32768 to 32767.

12. int → byte

int value = 100;
byte result = (byte) value;
System.out.println(result);

Output: 100. But if value = 130, output becomes -126. This is one of the most interesting casting examples.

13. short → byte

short value = 120;
byte result = (byte) value;
System.out.println(result);

Output: 120. But if value = 128, output becomes -128.

14. long → byte

long value = 100;
byte result = (byte) value;
System.out.println(result);

Output: 100. Again, if the value exceeds the byte range, overflow occurs.

15. float → int

float value = 65.99f;
int result = (int) value;
System.out.println(result);

Output: 65. The decimal portion disappears.

16. float → long

float value = 65.99f;
long result = (long) value;
System.out.println(result);

Output: 65.

17. float → short

float value = 100.5f;
short result = (short) value;
System.out.println(result);

Output: 100.

18. float → byte

float value = 100.5f;
byte result = (byte) value;
System.out.println(result);

Output: 100.

19. char → int

This conversion is very interesting.

char ch = 'A';
int number = (int) ch;
System.out.println(number);

Output: 65. Characters have numeric Unicode values. Some examples: 'A' → 65, 'B' → 66, 'a' → 97, '0' → 48.

20. int → char

The reverse is also possible.

int number = 65;
char ch = (char) number;
System.out.println(ch);

Output: A.

21. byte → char

This is an interesting combination.

byte byteValue = 65;
int intValue = byteValue;
char charValue = (char) intValue;
System.out.println(charValue);

Output: A. You can also directly cast: char charValue = (char) byteValue; The compiler performs the required conversion.

22. char → byte

This requires explicit casting.

char ch = 'A';
byte value = (byte) ch;
System.out.println(value);

Output: 65. But remember that char can contain values much larger than the range of byte. Therefore, data loss can occur.

23. char → short

char ch = 'A';
short value = (short) ch;
System.out.println(value);

Output: 65.

24. char → long

char ch = 'A';
long value = (long) ch;
System.out.println(value);

Output: 65.

25. char → float

char ch = 'A';
float value = (float) ch;
System.out.println(value);

Output: 65.0.

26. char → double

char ch = 'A';
double value = (double) ch;
System.out.println(value);

Output: 65.0.

27. The Most Important Difference: Casting vs Parsing

These are not the same thing.

Numeric casting:

double value = 65.79;
int number = (int) value;

Here, both are numeric types.

String parsing:

String value = "100";
int number = Integer.parseInt(value);

Here, "100" is a String, not a number. Therefore, (int) value is not how you convert a numeric String to an int. Use: Integer.parseInt(value)

28. String → int

String stringValue = "100";
int intValue = Integer.parseInt(stringValue);
System.out.println(intValue);

Output: 100

29. String → double

String stringValue = "25.5";
double value = Double.parseDouble(stringValue);
System.out.println(value);

Output: 25.5

30. String → float

String stringValue = "25.5";
float value = Float.parseFloat(stringValue);
System.out.println(value);

31. String → long

String stringValue = "100000";
long value = Long.parseLong(stringValue);
System.out.println(value);

32. String → short

String stringValue = "100";
short value = Short.parseShort(stringValue);
System.out.println(value);

33. String → byte

String stringValue = "100";
byte value = Byte.parseByte(stringValue);
System.out.println(value);

34. String → char

There is no Character.parseChar(). Instead, you can get a character using:

String value = "Hello";
char ch = value.charAt(0);
System.out.println(ch);

Output: H

35. Number → String

For converting a number to String:

int intValue = 100;
String stringValue = String.valueOf(intValue);
System.out.println(stringValue);

Output: 100. You can also use: String stringValue = Integer.toString(intValue);

36. Very Important: Casting Does NOT Change the Original Variable

Consider:

double value = 65.79;
int result = (int) value;

System.out.println(value);
System.out.println(result);

Output:

65.79
65

The original double is still 65.79. Casting creates a value of the target type; it does not permanently change the original variable.

37. Casting Does NOT Round

This is one of the best things to demonstrate to students.

double a = 10.9;
double b = 10.1;
double c = -10.9;

System.out.println((int) a);
System.out.println((int) b);
System.out.println((int) c);

Output:

10
10
-10

Casting simply removes the fractional part for floating-point-to-integer conversion.

38. Interesting Example: 300 → byte

Try this:

int value = 300;
byte result = (byte) value;
System.out.println(result);

Output: 44. Why? A byte contains only 8 bits. Its range is -128 to 127. Java keeps the low 8 bits of the integer representation. Conceptually: 300 → low 8 bits → 44. This is called narrowing conversion with overflow.

39. Interesting Example: 128 → byte

int value = 128;
byte result = (byte) value;
System.out.println(result);

Output: -128

And int value = 129; will output -127. This demonstrates the wrapping behavior of narrowing conversion.

40. Interesting Example: -1 → byte

int value = -1;
byte result = (byte) value;
System.out.println(result);

Output: -1. Internally, -1 has all bits set to 1 in two's complement representation (11111111). That same 8-bit pattern represents -1 as a byte.

41. Multiple Casting in One Expression

You can perform multiple conversions:

double value = 65.79;
byte result = (byte) (int) (long) value;
System.out.println(result);

Final result: 65

42. Casting in Arithmetic Expressions

This is very important in Java.

int a = 5;
int b = 2;
double result = (double) a / b;
System.out.println(result);

Output: 2.5

Without casting (int result = a / b;), the result is 2. Because a / b is integer division. Casting one operand changes the operation to floating-point division.

43. Integer Division Trick

int a = 10;
int b = 4;
System.out.println(a / b);
System.out.println((double) a / b);

Output:

2
2.5

44. Casting During Assignment

This will work: int number = (int) 10.5;

But the reverse requires no explicit cast: double value = 10; because Java can safely widen int to double.

45. Widening vs Explicit Narrowing

Widening: int value = 100; double result = value; (Usually safe)

Narrowing: double value = 100.5; int result = (int) value; (Potential data loss)

46. Quick Conversion Map

For the reverse direction, explicit casting is generally required:
double → float, long, int, short, byte
float → long, int, short, byte
long → int, short, byte
int → short, byte
short → byte

47. Important Rule for Students

Remember this simple rule: Big type → Small type = Explicit casting

Use: (targetType). Example: int value = (int) 65.79;

48. Casting vs Conversion

  • Casting: Usually refers to changing between compatible types using (int) value.
  • Parsing: Converting text into a primitive: Integer.parseInt("100").
  • Conversion: A broader term that can include String → int, double → int, etc.

49. Final Concept Map

                 TYPE CASTING
                      │
          ┌───────────┴───────────┐
          │                       │
      Widening                Narrowing
      Automatic                Explicit
          │                       │
    Small → Large             Large → Small
          │                       │
     int → double           double → int
     int → long             long → int
     char → int              int → byte
                              │
                              ↓
                         Data Loss Possible

The 5 things students should remember

  1. Explicit casting uses (type).
  2. Narrowing conversion generally requires explicit casting.
  3. Decimal values can be lost.
  4. Values can overflow when the target type has a smaller range.
  5. String conversion uses parsing methods, not primitive casting.

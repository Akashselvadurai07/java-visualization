1. What are Assignment Operators?

An assignment operator is used to assign a value to a variable. The most basic assignment operator is the equal sign (=), but Java provides compound assignment operators to perform an operation and assign the result in a single step.

Simple Example:

int x = 10;

x += 5; // Equivalent to: x = x + 5;

Here:

x += 5
 │ │ │
 │ │ └── The Value Added (5)
 │ └──── Compound Assignment Operator
 └────── The Target Variable (10)

The += operator tells Java to calculate 10 + 5 and store the result (15) directly back into x.

2. Types of Assignment Operators

Java provides several compound assignment operators based on standard math:

SymbolOperatorEquivalent Expression
=Simple Assignmenta = b
+=Add and Assigna = a + b
-=Subtract and Assigna = a - b
*=Multiply and Assigna = a * b
/=Divide and Assigna = a / b
%=Modulo and Assigna = a % b

3. Add and Assign +=

Adds the right side to the left side and assigns the result to the left variable.

int score = 50;
score += 10; // score becomes 60

4. Subtract and Assign -=

Subtracts the right side from the left side and assigns the result.

int health = 100;
health -= 15; // health becomes 85

5. Multiply and Assign *=

Multiplies the variable by the right side value.

int price = 10;
price *= 3; // price becomes 30

6. Divide /= and Modulo %=

Divides or finds the remainder, assigning back to the original variable.

int eggs = 26;
int dozen = eggs / 12;  // Standard Division
eggs %= 12;             // eggs becomes 2 (the remainder)

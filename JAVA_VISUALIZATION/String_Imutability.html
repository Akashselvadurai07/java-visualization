STRING IMMUTABILITY

1. Strings Cannot Change

In Java, String objects are immutable. Once a String is created in the Heap memory, its value can never be altered. Methods that seem to modify a string actually return a brand new String object.

2. The Concat Trap (s1.concat(s2))

When you call s1.concat(s2) on line 13, Java takes the values of s1 and s2 and creates a third String object in the heap. However, because you didn't assign the result back to a variable (like s1 = s1.concat(s2);), the reference to this new string is immediately lost. The new object becomes eligible for Garbage Collection.

3. The Final Output

Because the concatenation didn't change the original object, and you didn't reassign the s1 variable, printing s1 on line 15 outputs the exact same text you originally entered for s1.
